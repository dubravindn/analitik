## Рабочее окно

Проверить существующие процессы, исходники, интерпретаторы и отсутствие заданий. Приостановить только `hermes-ai-daily.timer`, если он был активен; убедиться, что daily/ai-daily задания не исполняются. После опустошения очереди остановить бот, вновь проверить очередь, затем остановить пустой worker. Только после новых сверок заменить три файла с сохранением владельцев/прав. Запустить worker и бот, проверить процессы, их идентификаторы и счётчики перезапуска, вернуть исходное состояние AI-таймера.

Запуск бота выполняет известные `db.apply_schema` и Telegram `setMyCommands`. Это реальные штатные побочные действия, а не запуск «без БД/Telegram». Текущая схема проверена отдельно; Python-откат не отменяет уже совершённые изменения БД. Возможна краткая недоступность аналитика во время окна. Пользовательские запросы, пришедшие в это время, могут потребовать повторения; отсутствие потерь всех сообщений не гарантируется.

Чтобы разрыв SSH не прервал замену файлов, после отдельного допуска возможен запуск одного временного задания systemd `hermes-night-install-20260912-4cb3`. Это одноразовая служба сопровождения, не постоянный таймер; она запускает только проверенный установщик и удаляется из активного реестра после завершения. Штатные unit-файлы приложения не редактируются. Это дополнительный явно заявленный эффект конкретного запуска.

## Отказ и приёмка

Обычная ошибка до замены возвращает только затронутые процессы/таймер в прежнее состояние. При ошибке после замены возможен файловый откат только при пустой очереди и проверенных трёх копиях. Нельзя убивать worker с заданием, перемещать JSON очереди, подменять неизвестно изменившиеся файлы или автоматически восстанавливать рабочую БД. Неопределённость означает сохранённое состояние и отдельное разбирательство, не слепой повтор.

Проверка работающих служб — техническая приёмка установки, не доказательство качества каждого ответа. Реальная проверка свободного вопроса владельцем остаётся отдельным следующим шагом. Установщик не отправляет тестовые сообщения в рабочую группу, не выбирает адресата и не меняет модель. Мост Telegram–Codex и остальные14 направлений сюда не входят.
